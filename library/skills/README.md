# Skills archive

Copies of skills for safekeeping and review. **Active** skills live in `~/workspace/custom-skills/` (custom) and `/opt/muse/skills/` (system, read-only) — the agent loads those. Files here are **archived copies, not active**: they exist so the skill text is versioned in git, reviewable, and restorable, and so a future agent can see what skills existed and what they said.

Pattern (Drew, 2026-10-21): going forward, review existing skills and create new ones whenever a workflow repeats. When a skill here is newer than the active copy, that's a finding to reconcile, not an instruction to auto-apply. The private repo (hatch-personal) mirrors this pattern at `library/skills/` for skills that shouldn't be public.
