# Reports

Dated outputs of work done in this repo: summaries, audits, analyses, backup ledgers. A report records what happened at a time; it is not maintained afterwards (corrections get a new dated report, or a note in the original).

If a report becomes standing reference material, it graduates to `library/` — reports are the inbox, the library is the shelf.
