# Muse — research dossier (archived 2026-09-30)

Full-scope archive of the deep research on Meta's Muse personal AI agent.
Companion web page: the "Muse Research Report" artifact (slug `muse-research-report`) — same content, browsable.

## What's here
- `report.md` — the complete dossier (11 sections + open questions + 47-source register).
  Every substantive claim is labeled OFFICIAL (Meta docs/statements), PRESS, or RUMOR (unverified).
- `notes/source-01-official.md` — per-source notes, official Meta materials.
- `notes/source-02-secondary.md` — per-source notes, press/community.
- `mission.md` — the verbatim research brief the dossier was built from.
- `social-posts.txt` — raw social-media trawl (IG/Threads/FB posts, launch buzz, referral-code spam,
  community reactions) saved from /tmp before it could be lost. Custom text format, not valid XML.

## The 11 sections
1. Release & creation — launched Sept 8, 2026; Meta's "personal superintelligence" pitch.
2. Relation to other Meta offerings — separate product from the Meta AI app and Muse Code (CLI);
   same Muse Spark model family; no announced merger.
3. Roadmap & intentions — Confidential VM, AI glasses, Realtime Voice/Avatar, Muse Charm device,
   agent email address, Mac computer use, small-business push; no ads in Muse.
4. Rumors — unreleased web screen-view tab + web voice-call UI found in builds; referral token claims
   (~1B/invite, max ~21B); pre-launch $199.99/mo tier that never shipped; OpenClaw/SOUL.md story.
5. Developer access — Muse Connectors opened ~Sept 18 (curated directory, apply at muse.ai/platform);
   NO published SDK/API spec/fees/revenue share; NO paid plug-in marketplace; no public consumer API.
6. Advanced/power uses — scheduled recurring tasks as the core automation primitive; bill-negotiation
   and refund showcases; community subagent/digest/inbox-triage examples.
7. Voice/audio — text-only at launch; Realtime Voice + Realtime Avatar announced/demoed, no GA date.
8. Tiers — Free $0 (help center publishes NO number, just "usage limit"; 100M/week is Zuckerberg's
   own Threads post, not official docs); Power $20/mo = 500M tokens/week; Maximum $100/mo = 3B/week.
   No overage billing — hard throttle, weekly refresh. No future tiers announced.
9. Avatars & image generation — name/avatar/tagline at onboarding; Realtime Avatar announced;
   no official plans for deeper custom image generation.
10. Personalization files — help center confirms a "file-based memory system" but never names
    SOUL.md/USER.md/MEMORY.md/IDENTITY.md; the per-file breakdowns are community-derived (OpenClaw lineage).
11. Conversation/context management — one ongoing conversation; layered self-curated memory;
    long chats compacted into summaries; Goals tab + Artifacts; "forget" command.

## Open questions the dossier could not resolve
- Free-tier token number in official docs (see section 8 caveat).
- Whether a payment card is truly required for the free tier (press conflicts).
- GA dates for agent email, Realtime Avatar, glasses integration, Charm pricing, Confidential VM.
- No evidence of paid plug-in marketplace, revenue share, or Muse Code ↔ consumer merger.
- How each personalization file precisely affects behavior — Meta has never documented it.
